El teu paquet de contingut

Afegeix exemples propis a qualsevol activitat (paraules, frases, textos i preguntes). Pots fer-los servir en aquest dispositiu o exportar-los com a fitxer per compartir-los amb altres dispositius o professionals.

Com ho comparteixo amb tots els dispositius?
  1. Prem Exporta el fitxer: es baixa un contingut.json.
  2. Publica'l en una adreça web accessible, per exemple dins del repositori de GitHub de l'app (a l'arrel, amb el nom contingut.json, el reben automàticament totes les còpies de la web i de l'app que se'n publiquin) o en qualsevol web que permeti l'accés des d'altres llocs (CORS), com GitHub Pages o un gist públic (adreça «raw»).
  3. A cada dispositiu, ves a Ajustos de lectura → Exemples i contingut, enganxa l'adreça i prem Desa i actualitza. A partir d'aquí, cada vegada que s'obri l'app es baixaran les novetats.
